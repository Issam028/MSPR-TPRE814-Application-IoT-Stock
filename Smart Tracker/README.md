# Smart Job Application Tracker

Smart Job Application Tracker is a front-end only Vue.js dashboard for students who want to organize job, internship, and alternance applications in one place.

## Features

- Dashboard with total applications, status statistics, response rate, and upcoming interviews or deadlines.
- Kanban board with five statuses: Applied, Interview, Waiting, Refused, and Accepted.
- Add, edit, delete, move, and update applications.
- Search and filters by company, city, technology, status, and contract type.
- Automatic LocalStorage saving with demo data when the app starts empty.
- Clear all data button and demo data reload button.
- Responsive layout for desktop and mobile.
- Toast messages for important actions.

## Technologies Used

- Vue 3
- Vite
- Composition API
- Plain CSS
- LocalStorage

## Install And Run

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.
